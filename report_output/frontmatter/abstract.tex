\chapter*{Abstract}
\thispagestyle{plain}
\addcontentsline{toc}{chapter}{Abstract}

Traditional electronic voting systems suffer from fundamental trust issues: centralized
databases can be manipulated by administrators, audit trails are often incomplete,
and voters have no independent mechanism to verify that their votes were recorded
correctly. This project addresses these challenges by designing and implementing a
hybrid cloud and distributed ledger e-voting system that leverages the Hedera
Consensus Service (HCS) for cryptographic immutability and transparent auditability.

The system adopts a Web2.5 architecture that decouples identity management from
vote consensus. In the implemented prototype, authentication and authorization are
handled by a Node.js/Express backend with JWTs and MongoDB, while vote recording
occurs on the Hedera testnet through an HCS topic. The backend prevents duplicate
participation with an atomic voter-state update and rolls that update back when the
HCS submission fails. The prototype does not claim ballot secrecy: the submitted
HCS message contains a candidate identifier and timestamp, so privacy and coercion
resistance remain limitations for future work.

Key features include: (1) a manifesto dashboard enabling informed voting through
candidate profiles, campus issues, and verifiable evidence documents; (2) a secure
voting booth with real-time transaction confirmation and HashScan audit links;
(3) an administrative console for election lifecycle management; and (4) transparent
tallying directly from Hedera mirror nodes, bypassing any centralized database.

The repository includes seven automated backend tests covering credential validation,
role-bearing JWT issuance, and Hedera error handling; all seven passed in the
recorded local run. The frontend production build also completed successfully.
End-to-end HCS latency, throughput, usability, and deployment-readiness claims are
not treated as measured results in this report and require a separately documented
test environment before any pilot deployment.
